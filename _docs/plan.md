# Plan: Household Chores App

## Overview
A tool for managing shared household chores among roommates or family members, with a focus on gamification and accountability.

## Core Features
1. **Gamified Tasks with Points:** Each chore is assigned a specific point value based on difficulty. Completing chores awards points to the user.
2. **Monthly Leaderboard:** A shared leaderboard tracks everyone's points. At the end of the month, the top earner can win a prize or bragging rights.
3. **Peer Review Verification:** To ensure chores are actually completed, another roommate must review and approve the task before points are officially awarded.
